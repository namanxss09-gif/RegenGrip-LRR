# Model assumptions
Constant speed, level road, still air, constant Crr. Excluded: slope, acceleration, regeneration, wind, tyre temperature dynamics,
load/pressure/temperature dependence of Crr (treated as test conditions only), dynamic load transfer, different front/rear tyre types.
Crr values for candidates are user inputs (hypothetical/target/measured), never derived from formulation. Demo values are ILLUSTRATIVE.
Ranking scale convention: a 20% Crr reduction scores 10/10 (a scaling choice, not physics). Sensitivity is deterministic, not statistical.
